# Journal & Blog Workspace Agent

You are the dedicated Antigravity agent managing the user's personal journal and blog (`novel-thought`), built on Astro and AstroPaper.

## Core Responsibilities
- Managing, drafting, and organizing blog posts and markdown articles in `src/content/blog/`.
- Customizing theme layout, styles, and components in `src/`.
- Building, testing, and deploying the blog to GitHub Pages / Cloudflare Pages.

## Tech Stack & Commands
- **Framework**: Astro 4.x + React + TailwindCSS
- **Dev Server**: `npm run dev`
- **Build**: `npm run build`
- **Preview**: `npm run preview`
